TOPIC 1: JAVASCRIPT FUNDAMENTALS & CORE CONCEPTS
================================================================================

[ 1.1 ] EXECUTION CONTEXT & HOISTING
--------------------------------------------------------------------------------
JavaScript executes code in two distinct phases within an Execution Context:
  1. Memory Creation Phase : Memory allocated for variables & functions.
                             (var initialized to undefined, functions loaded)
  2. Code Execution Phase  : Code runs line-by-line assigning values.

Hoisting is JS's behavior of hoisting declarations to top during Memory Phase.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Hoisting Behavior                                          |
  +--------------------------------------------------------------------------+
  |  // Function Hoisting                                                    |
  |  sayHello(); // [OK] Works because function declaration is fully hoisted |
  |  function sayHello() { console.log("Hello World!"); }                    |
  |                                                                          |
  |  // Variable Hoisting                                                    |
  |  console.log(a); // Output: undefined                                    |
  |  var a = 10;                                                             |
  |                                                                          |
  |  // console.log(b); // [ERROR] ReferenceError (Temporal Dead Zone - TDZ)  |
  |  let b = 20;                                                             |
  +--------------------------------------------------------------------------+


[ 1.2 ] STRICT MODE ("use strict")
--------------------------------------------------------------------------------
Strict mode enforces cleaner code and prevents silent errors by throwing 
exceptions for undeclared variables or unsafe actions.
Place "use strict"; at the top of a script file or function scope.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Strict Mode                                                |
  +--------------------------------------------------------------------------+
  |  "use strict";                                                           |
  |  console.log("Hello World");                                             |
  |  m = 100; // [ERROR] ReferenceError: m is not defined                    |
  +--------------------------------------------------------------------------+


[ 1.3 ] VARIABLE DECLARATIONS (var, let, const)
--------------------------------------------------------------------------------
JavaScript provides three keywords to declare variables: var, let, and const.

  +--------------+------------------+------------------+------------------+
  | FEATURE      | var              | let              | const            |
  +--------------+------------------+------------------+------------------+
  | Scope        | Function scope   | Block scope {}   | Block scope {}   |
  | Redeclarable | YES              | NO               | NO               |
  | Redefinable  | YES              | YES              | NO               |
  | Hoisting     | Initialized to   | Temporal Dead    | Temporal Dead    |
  |              | undefined        | Zone (TDZ)       | Zone (TDZ)       |
  +--------------+------------------+------------------+------------------+

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Variable Declarations                                      |
  +--------------------------------------------------------------------------+
  |  // --- let ---                                                          |
  |  let cName = "Tops Tech";                                                |
  |  cName = "CodeBite";    // [OK] Re-definition allowed                    |
  |  // let cName = "abc";  // [ERROR] SyntaxError: Already declared         |
  |                                                                          |
  |  // --- const ---                                                        |
  |  const PI = 3.14;                                                        |
  |  // PI = 2.7;           // [ERROR] TypeError: Assignment to constant    |
  |                                                                          |
  |  // --- var ---                                                          |
  |  var m = 100;                                                            |
  |  var m = 400;           // [OK] Redeclaration and re-definition allowed  |
  |  console.log(m);        // Output: 400                                   |
  +--------------------------------------------------------------------------+


[ 1.4 ] COMMENTS & TEMPLATE LITERALS
--------------------------------------------------------------------------------
  • Single-line Comment  : //
  • Multi-line Comment   : /* ... */
  • Template Literals    : Backticks `` ` `` allow string interpolation 
                           `${expression}` and multi-line formatting.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Template Literals                                          |
  +--------------------------------------------------------------------------+
  |  let name = "Megha";                                                     |
  |  let role = "Instructor";                                                |
  |  let greeting = `Hello ${name}, role: ${role}.                           |
  |  Welcome to JS!`;                                                        |
  |  console.log(greeting);                                                  |
  +--------------------------------------------------------------------------+


[ 1.5 ] USER INTERACTION MODALS
--------------------------------------------------------------------------------
JavaScript provides three built-in modal dialog boxes:

  1. alert(message)   : Displays an informational pop-up to the user.
  2. prompt(message)  : Prompts the user for text input (returns string/null).
  3. confirm(message) : Asks for confirmation (returns boolean: true/false).

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Interaction Modals                                         |
  +--------------------------------------------------------------------------+
  |  alert("Welcome to JS tutorial");                                        |
  |  let userName = prompt("Enter your name");                               |
  |  let isConfirmed = confirm("Are you sure to delete items?");             |
  |  if (isConfirmed) alert("Deleted!");                                     |
  +--------------------------------------------------------------------------+

TOPIC 2: DATA TYPES, CONVERSION & OPERATORS
================================================================================

[ 2.1 ] PRIMITIVE VS NON-PRIMITIVE DATA TYPES
--------------------------------------------------------------------------------
  • Primitive Types    : Number, BigInt, String, Symbol, Null, Undefined, Boolean
  • Non-Primitive Type : Object (including Arrays & Functions)

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Checking Types with typeof                                 |
  +--------------------------------------------------------------------------+
  |  let num1 = 123;                         // typeof -> "number"          |
  |  let largeNum = 12378797987878978998n;   // typeof -> "bigint"          |
  |  let name = "Manthan";                   // typeof -> "string"          |
  |  let sym = Symbol("id");                 // typeof -> "symbol"          |
  |  let res = null;                         // typeof -> "object" (quirk)  |
  |  let m;                                  // typeof -> "undefined"       |
  |  let flag = true;                        // typeof -> "boolean"         |
  |  let user = { name: 'abc' };             // typeof -> "object"          |
  +--------------------------------------------------------------------------+


[ 2.2 ] TRUTHY & FALSY VALUES
--------------------------------------------------------------------------------
The 6 Falsy Values in JavaScript:
  1. false
  2. 0 (and -0, 0n)
  3. "" (empty string)
  4. null
  5. undefined
  6. NaN

*Every other value in JS is TRUTHY (including "0", "false", [], {}, function(){}).


[ 2.3 ] LOOSE EQUALITY (==) VS STRICT EQUALITY (===)
--------------------------------------------------------------------------------
  • Loose Equality (==)   : Performs implicit coercion before comparing.
  • Strict Equality (===) : Compares both VALUE and DATA TYPE without coercion.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Equality Comparison                                        |
  +--------------------------------------------------------------------------+
  |  console.log(5 == "5");         // Output: true  (string coerced)       |
  |  console.log(5 === "5");        // Output: false (different types)      |
  |  console.log(null == undefined);// Output: true                         |
  |  console.log(null === undefined);// Output: false                        |
  +--------------------------------------------------------------------------+


[ 2.4 ] TYPE CONVERSION & TYPE COERCION
--------------------------------------------------------------------------------
Implicit Coercion : Automatic conversion during evaluation (+, *, /).
Explicit Conversion: Manual conversion via Number(), String(), Boolean().

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Type Conversion Rules                                      |
  +--------------------------------------------------------------------------+
  |  console.log("12" + 3);    // Output: "123" (String concatenation)        |
  |  console.log(2 + 2 + "1"); // Output: "41"  (Left to right)              |
  |  console.log("12" * 3);    // Output: 36    (Numeric coercion)          |
  |  console.log("6" / "2");   // Output: 3                                    |
  |                                                                          |
  |  console.log(Number("123")); // Output: 123                              |
  |  console.log(Number("abc")); // Output: NaN                              |
  |                                                                          |
  |  let num = +prompt("Enter num"); // Unary + converts to number           |
  |  console.log(3 > 2 > 1);     // Output: false (true > 1 -> 1 > 1)        |
  +--------------------------------------------------------------------------+


[ 2.5 ] ADVANCED OPERATORS (??, &&, ||, Ternary)
--------------------------------------------------------------------------------
  • Ternary Operator        : condition ? valIfTrue : valIfFalse
  • Nullish Coalescing (??) : Returns right side ONLY if left is null/undefined.
  • Logical OR (||)         : Returns right side if left is ANY falsy value.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Ternary & Nullish vs Logical OR                            |
  +--------------------------------------------------------------------------+
  |  let age = 20;                                                           |
  |  let status = (age >= 18) ? "Adult" : "Minor";                           |
  |                                                                          |
  |  let count = 0;                                                          |
  |  console.log(count || 10); // Output: 10 (0 is falsy, falls back)        |
  |  console.log(count ?? 10); // Output: 0  (0 is preserved!)              |
  +--------------------------------------------------------------------------+

  | CODE EXAMPLE: Calculator via Switch-Case                                 |
  +--------------------------------------------------------------------------+
  |  function calculate(num1, num2, op) {                                    |
  |      let res;                                                            |
  |      switch(op) {                                                        |
  |          case '+': res = num1 + num2; break;                             |
  |          case '-': res = num1 - num2; break;                             |

[ 3.3 ] ITERATIVE LOOPS & LOOP CONTROL (break, continue)
--------------------------------------------------------------------------------
  • while & for : Entry-controlled loops.
  • do...while  : Exit-controlled loop (executes at least ONCE).
  • break       : Exits the loop entirely.
  • continue    : Skips current iteration and moves to next.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Loops, Controls & Chessboard Grid                         |
  +--------------------------------------------------------------------------+
  |  // Loop Control Statements                                              |
  |  for (let k = 1; k <= 10; k++) {                                         |
  |      if (k === 3) continue; // Skip 3                                    |
  |      if (k === 7) break;    // Stop loop at 7                            |
  |      console.log(k);        // Prints 1, 2, 4, 5, 6                      |
  |  }                                                                       |
  |                                                                          |
  |  // Chessboard Grid Generation                                           |
  |  function chessGen() {                                                   |
  |      let str = "";                                                       |
  |      for (let i = 1; i <= 8; i++) {                                      |
  |          str += "<div>";                                                 |
  |          for (let j = 1; j <= 8; j++) {                                  |
  |              str += ((i+j)%2 === 0) ? `<span class="black">${i}</span>`  |
  |                                     : `<span class="white">${i}</span>`; |
  |          }                                                               |
  |          str += "</div>";                                                |
  |      }                                                                   |
  |      document.getElementById('main').innerHTML = str;                    |
  |  }                                                                       |
  +--------------------------------------------------------------------------+

TOPIC 4: FUNCTIONS & FUNCTIONAL PROGRAMMING
================================================================================

[ 4.1 ] FUNCTION DECLARATIONS, SCOPE CHAIN & REST PARAMETERS
--------------------------------------------------------------------------------
  • Rest Parameters (...args) : Collects arbitrary arguments into an array.
  • Scope Chain              : Inner functions can access variables from 
                               outer lexical environments.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Declarations, Rest Params & Scope                          |
  +--------------------------------------------------------------------------+
  |  // Rest Parameters                                                      |
  |  function sumAll(...numbers) {                                           |
  |      return numbers.reduce((total, n) => total + n, 0);                  |
  |  }                                                                       |
  |  console.log(sumAll(10, 20, 30)); // Output: 60                          |
  |                                                                          |
  |  // Scope Chain                                                          |
  |  let globalVar = "Global";                                               |
  |  function outer() {                                                      |
  |      let outerVar = "Outer";                                             |
  |      function inner() { console.log(outerVar, globalVar); }              |
  |      inner();                                                            |
  |  }                                                                       |
  +--------------------------------------------------------------------------+


[ 4.2 ] FUNCTION EXPRESSIONS, ARROW FUNCTIONS & IIFE
--------------------------------------------------------------------------------
  • IIFE : Immediately Invoked Function Expression runs immediately upon creation.

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Expressions, Arrows & IIFE                                 |
  +--------------------------------------------------------------------------+
  |  const add = function(a, b) { return a + b; };                           |
  |  const multiply = (a, b) => a * b;                                       |
  |                                                                          |
  |  // IIFE                                                                 |
  |  (function() {                                                           |
  |      console.log("IIFE executed immediately!");                          |
  |  })();                                                                   |
  +--------------------------------------------------------------------------+


[ 4.3 ] CALLBACK FUNCTIONS & PURE VS IMPURE FUNCTIONS
--------------------------------------------------------------------------------
  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Callback Pattern                                           |
  +--------------------------------------------------------------------------+
  |  function even(num) { console.log(`${num} is Even`); }                  |
  |  function odd(num)  { console.log(`${num} is Odd`); }                   |
  |                                                                          |
  |  function FindEvenOdd(cb1, cb2) {                                       |
  |      let num = prompt("Enter number");                                   |
  |      (num % 2 == 0) ? cb1(num) : cb2(num);                               |
  |  }                                                                       |
  |  FindEvenOdd(even, odd);                                                 |
  +--------------------------------------------------------------------------+

[ 5.3 ] OBJECT METHODS, THIS KEYWORD & PASS-BY-REFERENCE
--------------------------------------------------------------------------------
  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Pass-by-Reference vs Object.assign()                       |
  +--------------------------------------------------------------------------+
  |  let user = { uname: "abc" };                                            |
  |  let admin = user;        // Copies memory address reference             |
  |  admin.uname = "john";                                                   |
  |  console.log(user.uname); // Output: "john" (original mutated)           |
  |                                                                          |
  |  // Shallow Copy via Object.assign()                                     |
  |  let copy = {};                                                          |
  |  Object.assign(copy, user);                                              |
  |  copy.uname = "Sufiyan";                                                 |
  |  console.log(user.uname); // Output: "john" (original safe)              |
  +--------------------------------------------------------------------------+

[ 7.2 ] EVENT PROPAGATION: CAPTURING VS BUBBLING
--------------------------------------------------------------------------------
Event propagation occurs in 3 phases:
  1. Capturing Phase : Event travels down from window -> document -> ancestors -> target
  2. Target Phase    : Event reaches target element
  3. Bubbling Phase  : Event bubbles back up from target -> ancestors -> window

  +--------------------------------------------------------------------------+
  | CODE EXAMPLE: Event Bubbling & stopPropagation()                         |
  +--------------------------------------------------------------------------+
  |  child.addEventListener('click', (e) => {                                |
  |      console.log("Child clicked");                                       |
  |      e.stopPropagation(); // Halts bubbling up to parent!               |
  |  });                                                                     |
  |                                                                          |
  |  parent.addEventListener('click', (e) => {                               |
  |      console.log("Target:", e.target);                                   |
  |      console.log("Current Target:", e.currentTarget);                   |
  |  });                                                                     |
  +--------------------------------------------------------------------------+
