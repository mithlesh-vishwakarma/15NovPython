# Session 5: Events, Controlled Inputs, and Forms

## Implemented Tasks
1. `LikeButton`: Event-driven state counter incrementing on click.
2. `SearchBar`: Controlled input state displaying real-time input preview as the user types.
3. `LoginForm`: Controlled username and password inputs, form submit handler with `e.preventDefault()`, alerts credentials locally (per assignment), and safely clears both fields without page reload.
4. `PlaylistAdder`: Controlled form with song and artist inputs, appending items to a state array with unique IDs, rendering a list below.
5. Used React state throughout, with stable keys for mapped list elements.

## How to Run

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
# or
npm start
```

### Production Build
```bash
npm run build
```
