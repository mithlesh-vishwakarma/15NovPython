# Session 3: Props, Defaults, and Prop Validation

## Implemented Tasks
1. Created `ProductCard` component accepting `productName` and `price`, styled as an ecommerce product card.
2. Created `UserProfile` component accepting `username`, `followers`, and `profilePic`, styled like an Instagram user card.
3. Configured `UserProfile.defaultProps` to default `followers` to `0` and `profilePic` to a default placeholder avatar.
4. Added runtime prop validation to `ProductCard` via `prop-types` (`PropTypes.string` and `PropTypes.number`).
5. Implemented interactive demo in `App.jsx` showcasing both standard props and fallback default props.

## How to Run

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
# or
npm start
```

### Production Build
```bash
npm run build
```
