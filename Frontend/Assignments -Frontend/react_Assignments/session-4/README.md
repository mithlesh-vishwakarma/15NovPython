# Session 4: useState Interaction Exercises

## Implemented Tasks
1. `LikeButton`: Heart button with counter state starting at 0, incrementing on each click.
2. `CartItem`: Item quantity controls starting at 1, incrementing on plus, decrementing with lower-bound check preventing negative values (< 0).
3. `SongVote`: Song title with upvote/downvote controls and a non-negative vote boundary.
4. `StarRating`: 5-star interactive selector highlighting current and previous stars with hover preview and persistent state on click.
5. `App.jsx`: Renders all 4 interactive components with responsive layout.

## How to Run

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
# or
npm start
```

### Production Build
```bash
npm run build
```
