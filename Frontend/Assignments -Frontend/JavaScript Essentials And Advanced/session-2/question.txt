3.Declare a constant called MAX_POSTS with value 100 and try to reassign it to 200. Observe and note what error or message appears in the console.<br><br><em><strong>Hint:</strong> Use const for MAX_POSTS and see what happens when you attempt reassignment.</em>

Explain in a comment why this works even though the array was declared with const.<br><br><em><strong>Hint:</strong> const prevents reassignment of the variable, not mutation of the array contents.</em>

5.Build a JavaScript object called spotifyProfile with properties: userName (string), playlists (array of strings), and isPremium (boolean). Log the object and access the playlists property in the console.

7.Show the difference between primitive and reference types by creating a variable favFood = 'pizza' and another variable favFoodCopy = favFood. Change favFood to 'burger' and log both variables. Then, create an object zomatoUser with a property city, assign it to another variable, change the city in one, and log both objects.<br><br><em><strong>Hint:</strong> Observe how changes affect primitives vs objects.</em>

9.Write a function displayProfile that takes a userName and followers as parameters and prints a formatted string like 'Aarya has 1500 followers' to the console. Call this function with your own details.
