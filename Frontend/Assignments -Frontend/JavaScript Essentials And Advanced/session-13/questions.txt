JAVASCRIPT ERROR HANDLING TASKS

1. VALIDATE SPOTIFY URL

Create a function validateSpotifyURL(url) that takes a string and checks if it starts with "https://open.spotify.com/". If not, throw a custom Error with the message "Invalid Spotify URL".


2. VALIDATE USERNAME

Create a function validateUsername(username) that checks if the username contains only letters and numbers. If not, use throw to raise a custom Error with the message "Invalid Username".

Wrap the function call in try...catch and display the error message in the console.


3. PARSE FLIPKART PRODUCT JSON

Write a try...catch...finally block that tries to parse a JSON string representing a Flipkart product:

'{"name":"Shoes","price":999}'

If parsing fails, catch the error and log "Invalid product data".

In the finally block, log "Parsing attempt finished".


4. VALIDATE PLAYLIST URL

Build a function checkPlaylistURL(url) for a Spotify-style app that validates whether the URL starts with "https://open.spotify.com/".

If not, throw a custom Error("Invalid Spotify URL").

Use try...catch...finally to handle the error, log the error message, and in the finally block log "Validation complete".


5. VALIDATE PAYMENT AMOUNT

Build a function checkPaymentAmount(amount) for a Paytm-style app.

If the amount is less than or equal to zero, throw a custom Error with the message "Amount must be positive".

Otherwise, return "Payment accepted".

Hint: Use the throw statement to raise your custom error inside the function.


6. CALCULATE ZOMATO ORDER TOTAL

Write a function getOrderTotal(items) for a Zomato-style food order, where items is an array of objects containing name and price.

Example:

const items = [
    { name: "Pizza", price: 299 },
    { name: "Burger", price: 149 },
    { name: "Coke", price: 50 }
];

If any item's price is negative, throw a custom Error("Invalid item price").

Use try...catch to handle the error and display a friendly message.


7. HANDLE UNDEFINED USER DATA

Given this buggy code:

let user;

try {
    console.log(user.name);
} catch (e) {
    // handle error
}

Modify it so that accessing the undefined user's name is handled properly.

The user-friendly error message should be "User data not found".


8. FIX ERROR OBJECT HANDLING

Given this buggy function:

function formatFollowers(count) {
    try {
        if (count < 0) throw "Negative count";

        return count + " followers";
    } catch (e) {
        return e.message;
    }
}

The function currently returns undefined when count is negative.

Fix the code so that it properly throws and catches an Error object.

Hint: Use an Error object instead of throwing a string.


9. UNDERSTAND A JAVASCRIPT STACK TRACE

Create a JavaScript example that throws a custom error:

throw new Error("Something went wrong");

Run it in your browser console and copy the resulting stack trace.

Then explain:

- What the error message means
- What a stack trace is
- Which function caused the error
- Which line caused the error
- Why the error occurred

Finally, write a short summary in your own words as a comment above the code.
