4. Default Parameter with Quantity

Hint:

9. Arrow Function and Rest Parameters

Refactor this function to use an arrow function and rest parameters:

function addToCart() {
    let total = 0;

    for(let i = 0; i < arguments.length; i++) {
        total += arguments[i];
    }

    return total;
}

The new function should be called addToCartArrow and accept any number of prices as arguments, returning their sum.
