Task 9: Debug Movie Names Code

Question: Debug this code: It tries to save an array of movie names to localStorage, but after reloading, the list doesn't display correctly.

The Problem:

let movies = ['Jawan', 'Pathaan', 'Dunki'];
localStorage.setItem('movies', movies);
let saved = localStorage.getItem('movies');
let arr = JSON.parse(saved);
console.log(arr);

The Solution:

Issue: The array is converted to a comma-separated string (not JSON), so JSON.parse() fails.

Fix: Use JSON.stringify() to convert the array to a proper JSON string before saving. 

let movies = ['Jawan', 'Pathaan', 'Dunki'];
localStorage.setItem('movies', JSON.stringify(movies));  // Convert to JSON
let saved = localStorage.getItem('movies');
let arr = JSON.parse(saved);  // Now this will work correctly
console.log(arr);
